# Bernards Estate Agents — Website Upgrade Brief

## URLs
- **Current live site:** https://bernardsestates.co.uk/
- **Staging site (Elementor):** https://bernardsestateagents.live-website.com/
- **Reference/model:** https://www.rightmove.co.uk/

## Core Objective
Take the new WordPress/Elementor staging site and integrate a proper real-estate property system so it:
- Replicates the functionality and UX of Rightmove
- Uses/mirrors content and fields from the current live site
- Looks modern, slick, and user-friendly

## Functional Requirements

### 1. Property Plugin / Real Estate System
- WordPress-based property management system
- Manage listings, filters, detail pages
- Integrate into existing Elementor site
- Map and migrate all fields from current live site

### 2. Search & Filtering (Rightmove-style)
**Homepage:**
- Simple primary search (Buy | Rent | Sold)
- Clean, modern search interface

**Search Results:**
- Property listing page showing all properties
- Filters: For Sale, To Rent, New Homes, Price, Property Type, etc.

**Single Property Pages:**
- Rightmove-style layout
- Clean, structured info
- Focus on visuals and key info
- "Slick" design

### 3. Data Handling & Import
- Build structure first, import data later
- Import via CSV or XML
- Export from current live site's property system
- Import into new system once ready
